## 🧭 О проекте

**SonestaTour** — сайт туристического агентства. Пользователи могут просматривать направления и отели, искать туры, добавлять отели в избранное и корзину, а также оформлять заявку на бронирование.

Приложение построено по клиент-серверной схеме:

- **Фронтенд** — статический сайт на HTML / CSS / JavaScript.
- **Бэкенд** — сервер на Node.js (Express) с REST API.
- **Хранение данных** — в памяти сервера (массив отелей + `Map` корзин).

| Параметр | Значение |
|----------|----------|
| HTML-страниц | 20 |
| Отелей в каталоге | 9 (2–7 звёзд) |
| Направлений | 10 |
| Объём кода | ≈ 3800 строк (JS + CSS + HTML) |
| Адрес по умолчанию | `http://localhost:3000` |

## 🏗 Архитектура

Сервер на Express раздаёт статические файлы сайта и обрабатывает запросы к REST API. Браузер загружает страницы и обращается к серверу за данными через Fetch API. Данные (каталог отелей и корзины) хранятся в памяти сервера.

```
┌────────────────┐    HTTP / JSON      ┌────────────────────────┐
│    КЛИЕНТ       │ ──────────────────► │   СЕРВЕР (Express)      │
│   браузер       │   fetch + cookie    │   server.js            │
│   HTML/CSS/JS   │ ◄────────────────── │   REST API + статика   │
└────────────────┘                     └───────────┬────────────┘
                                                    │
                                                    ▼
                                        ┌────────────────────────┐
                                        │   Хранилище в памяти    │
                                        │   Map: отели, корзины   │
                                        └────────────────────────┘
```

## 🔌 REST API

Базовый адрес: `http://localhost:3000` · Формат — JSON.
Запросы корзины требуют передачи cookie (`credentials: 'include'`).

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET` | `/api/hotels` | Список отелей. Параметры: `q`, `minStars`, `maxStars` |
| `GET` | `/api/cart` | Состояние корзины |
| `POST` | `/api/cart/items` | Добавить отель `{ hotelId, quantity }` |
| `PATCH` | `/api/cart/items/:id` | Изменить количество (`0` → удалить, макс. 99) |
| `DELETE` | `/api/cart/items/:id` | Удалить позицию |

### Пример: поиск отелей

**Запрос**

```http
GET /api/hotels?q=дубай&minStars=5
```

**Ответ**

```json
{
  "items": [
    {
      "id": "burj-al-arab-dubai",
      "name": "Burj Al Arab Dubai",
      "location": "Дубай, ОАЭ",
      "stars": 7,
      "pricePerNight": 85000,
      "tags": ["All Inclusive", "Приватный пляж", "Бассейн"],
      "detailsUrl": "/hotel-burj.html"
    }
  ]
}
```

### Пример: добавление в корзину

**Запрос**

```http
POST /api/cart/items
Content-Type: application/json

{ "hotelId": "burj-al-arab-dubai", "quantity": 2 }
```

**Ответ**

```json
{
  "items": [
    { "hotel": { "id": "burj-al-arab-dubai" }, "quantity": 2, "lineTotal": 170000 }
  ],
  "totalCount": 2,
  "totalPrice": 170000
}
```

> При неизвестном `hotelId` сервер возвращает `400 { "error": "Unknown hotelId" }`.

## 🗄 Модель данных

### Отель на сервере (для API)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | строка | Идентификатор |
| `name` | строка | Название |
| `location` | строка | Расположение |
| `stars` | число | Звёзды (2–7) |
| `pricePerNight` | число | Цена за ночь |
| `image` | строка | Путь к изображению |
| `tags` | массив | Метки для поиска |
| `detailsUrl` | строка | Ссылка на страницу отеля |

### Отель на клиенте (`data.js`)

Дополнительно содержит: `price`, `category`, `images[]`, `features`, `amenities`, `roomTypes` (тип, площадь, гости, цена), `rating`, `reviews`.

### Хранение на клиенте

| Хранилище | Что хранит |
|-----------|------------|
| `localStorage` | Избранные отели |
| `sessionStorage` | Параметры поиска и данные бронирования |
| cookie `cartId` | Идентификатор корзины (создаётся сервером) |

## 🧪 Тестирование

Для проверки REST API написан набор автотестов на встроенном раннере `node:test` с модулем `node:assert`. Тесты поднимают сервер на отдельном порту и проверяют отели, фильтры, корзину и изоляцию корзин разных пользователей. Дополнительно проводилось ручное тестирование интерфейса.

### Запуск тестов

```bash
npm install
node --test
```

### Набор тест-кейсов

| № | Что проверяется | Ожидаемый результат |
|--:|-----------------|---------------------|
| 1 | `GET /api/hotels` | Возвращаются все 9 отелей, HTTP 200 |
| 2 | `GET /api/hotels?q=dubai` | Найден отель в Дубае |
| 3 | `GET /api/hotels?minStars=6` | Только отели 6–7 звёзд (3 шт.) |
| 4 | `GET /api/hotels?maxStars=3` | Только отели ≤ 3 звёзд (3 шт.) |
| 5 | `GET /api/cart` | Создаётся корзина, выдаётся cookie `cartId` |
| 6 | `POST /api/cart/items` | Сумма 85000 × 2 = 170000 ₽ |
| 7 | `POST` с неизвестным `id` | HTTP 400, текст ошибки |
| 8 | `PATCH` количество | Количество меняется на заданное |
| 9 | `PATCH quantity=0` | Позиция удаляется |
| 10 | `DELETE` позиции | Позиция удаляется, HTTP 200 |
| 11 | Изоляция корзин | Корзины разных cookie независимы |
| 12 | Ручной тест UI | Поиск, корзина, избранное, форма, адаптивность |

### Результаты

✅ Логика данных и фильтрации подтверждена: в каталоге 9 отелей; `minStars=6` возвращает 3 отеля; `maxStars=3` — 3 отеля; стоимость Burj Al Arab 85000 × 2 = 170000 ₽. **Критических ошибок не выявлено.**

## 🔒 Безопасность

- **Защита от XSS** — внешний текст экранируется функцией `escapeHtml` при отрисовке.
- **Безопасные cookie** — cookie корзины с флагами `HttpOnly` и `SameSite=Lax`.
- **Серверная валидация** — проверка `hotelId` и приведение количества к допустимому диапазону.

## 📈 Ограничения и развитие

### Текущие ограничения

- Данные хранятся в памяти и сбрасываются при перезапуске сервера.
- Нет авторизации и личного кабинета.
- Бронирование имитируется на клиенте (без реальной оплаты).
- Клиентский и серверный наборы данных ведутся раздельно.

### Планы развития

- [ ] Перенос данных в базу данных (PostgreSQL).
- [ ] Авторизация и личный кабинет пользователя.
- [ ] Онлайн-оплата бронирования.
- [ ] Постоянное хранение корзины.
